Every name used in the product, with the one way to write it, in code and on screen. Definitions live
in the domain; this page only names ([`RULE-01`](https://github.com/openpedd/openpedd/blob/main/spec/foundations/rules/writing.md#rule-01)).

`Name` is the name in code, in English. Each locale of `locales` in `workspace.yaml` has a column,
headed by its code, with what a person reads on screen; one left empty shows the name
([`DEC-33`](https://github.com/openpedd/openpedd/blob/main/spec/decisions/DEC-33-names-per-locale.md)).
Add a column when you add a locale, for example `es`.
