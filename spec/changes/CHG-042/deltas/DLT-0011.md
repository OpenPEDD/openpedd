# DLT-0011 · `start_step` and `deliver_step` are `pedd step`, until the MCP exists

| Field | Value |
|---|---|
| `target` | `ARCH-04`, [MCP tools](../../../foundations/architecture/agents.md#mcp-tools) |
| `op` | `MODIFIED` |
| `type` | `deviation` |
| `stage` | `build` |
| `change` | `CHG-042` |
| `reason` | The pedd MCP server is specified and not built; an agent already runs `pedd` from its shell |
| `alternative` | Build the MCP server first, with only these two tools |
| `revert` | `packages/cli/src/steps.mjs`: `startStep`, `deliverStep`; the MCP tools call them when the server exists |
| `evidence` | `packages/cli/src/cli.mjs`: `NOT_BUILT` names no MCP server; nothing under `packages/` serves one |
| `if_no` | The step clock waits for the MCP server |

**Proposed text:** `pedd step start <stage> [--change CHG-nnn] [--prd <path>] [--flow F<n>] [--piece a,b]`
prints the step's ID; `pedd step deliver|pass|reject [<step>]` closes it, the person's open step when no ID
is given. The time and the person are the tool's: the clock, and git `user.email` (`--as` only for a judge
that runs as another).
