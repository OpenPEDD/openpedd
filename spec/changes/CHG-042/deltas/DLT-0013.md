# DLT-0013 · Which step is open, and which pieces a step carries

| Field | Value |
|---|---|
| `target` | `ENT-23`, [steps](../../../foundations/domain/trace-event.md#steps) and [pieces](../../../foundations/domain/trace-event.md#pieces) |

| `type` | `assumption` |
| `stage` | `build` |
| `change` | `CHG-042` |
| `reason` | ENT-23 says a message carries the step open, not which one when a person has several; and a step on a whole PRD names no flow |
| `alternative` | One open step per session, named by the agent |

| `evidence` | guess |

**Proposed text:** A person's open step is the last one they started or that was rejected, and not
delivered since. A step's pieces are `--piece`, else the `Piece:` line under its flow's heading, else every
piece the PRD names in its flows and its `Piece` column of screens.
