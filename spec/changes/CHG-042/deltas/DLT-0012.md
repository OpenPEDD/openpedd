# DLT-0012 · `pedd init` installs only the human clock, for now

| Field | Value |
|---|---|
| `target` | [Workspace, main flow](../../../modules/workspace/prd.md#main-flow), step 9 |
| `op` | `MODIFIED` |
| `type` | `deviation` |
| `stage` | `build` |
| `change` | `CHG-042` |
| `reason` | The onboarding is not built: the template is copied by hand. The two projects to measure exist already and need only the hook |
| `alternative` | A command of its own, `pedd install clock` |
| `revert` | `packages/cli/src/clock.mjs`: `installClock`; `init` in `cli.mjs` returns to `NOT_BUILT` |
| `evidence` | `packages/cli/src/cli.mjs`: `NOT_BUILT.init` |
| `if_no` | The hook is added to each project by hand |

**Proposed text:** `pedd init` on a project that has a `workspace.yaml` installs [the human clock](../../../modules/workspace/prd.md#the-human-clock)
and says the rest of the onboarding is not built. It writes only what is missing, keeps every other hook,
backs up `.claude/settings.json` in `.pedd/backups/<date>/` before changing it, and `--dry-run` prints what it would write.
