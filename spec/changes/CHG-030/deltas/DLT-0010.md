# DLT-0010 · `pedd view`'s options and outputs

| Field | Value |
|---|---|
| `target` | `FR-VEW-07`, [requirements](../../../modules/views/prd.md#requirements) |
| `op` | `MODIFIED` |
| `type` | `assumption` |
| `stage` | `build` |
| `change` | `CHG-030` |
| `reason` | A page opened from a file cannot be told to reload; Mermaid pasted in a PR renders only inside a `mermaid` block; and `npm run view` wrote the framework map to `.pedd/view/index.html`, the file `pedd view` writes |
| `alternative` | A page that polls its own file every second |
| `revert` | `packages/cli/src/view.mjs`: `watchViews`; `packages/reader/src/views/mermaid.mjs`; `scripts/view.mjs` |

**Proposed text:** `pedd view --watch` serves the page and the working tree on `127.0.0.1` (`--port`),
rebuilds on each save of the spec and sends the page an event that reloads it. `--format mermaid`
prints Markdown: the graph in a `mermaid` block and each matrix as a table. `--no-open` writes without
opening; `pedd check --json` prints the checks as JSON, the run the success metric counts. The
framework map of `npm run view` goes to `.pedd/map/`.
