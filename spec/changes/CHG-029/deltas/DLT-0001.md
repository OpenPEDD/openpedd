# DLT-0001 · The body of `definition.md`

| Field | Value |
|---|---|
| `target` | `ARCH-18`, [the file](../../../foundations/architecture/definition.md#the-file) |
| `op` | `MODIFIED` |
| `type` | `assumption` |
| `stage` | `build` |
| `change` | `CHG-029` |
| `reason` | The spec says the body holds each item with its state and the client's words, then the summary, but not how; `readDefinition` and `writeDefinition` need one form |
| `alternative` | Items as a list of headings, one per item |
| `revert` | `packages/reader/src/definition.mjs`: `itemsTable` and `renderItems` |

**Proposed text:** the body holds a `## Items` table with the columns `Item` · `State` · `Client's words`,
the state one of `answered` · `assumed` · `deferred` · `missing`, then a `## Summary` section. Text
outside them is kept as written.
