# DLT-0003 · How the reader finds requirements

| Field | Value |
|---|---|
| `target` | `ENT-03`, [fields](../../../foundations/domain/requirement.md#fields) |
| `op` | `MODIFIED` |
| `type` | `assumption` |
| `stage` | `build` |
| `change` | `CHG-029` |
| `reason` | No PRD has a requirements table yet; the reader needs to know one when it sees it |
| `alternative` | Only the table under a `Requirements` heading |
| `revert` | `packages/reader/src/spec.mjs`: `requirementsOf` |

**Proposed text:** a requirement is a row of any table in a PRD whose `ID` column, or first column,
holds `FR-<MOD>-nn` or `NFR-<MOD>-nn`. Its status is the `Status` column; empty or absent, the PRD's.
