# DLT-0002 · The reader gives the map's data

| Field | Value |
|---|---|
| `target` | `ARCH-20`, [what it does](../../../foundations/architecture/reader.md#what-it-does) |
| `op` | `MODIFIED` |
| `type` | `assumption` |
| `stage` | `build` |
| `change` | `CHG-029` |
| `reason` | The Cloud's map reads the data, not the page, and must not run code from its clone: it runs its pinned reader on the clone's text |

`.pedd/view/map.json`; `renderMap` inlines it in the page. `openpedd-reader map <root>` prints it for a
folder read as text.
