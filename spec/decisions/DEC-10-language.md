# DEC-10 · English everywhere

**Closes:** `Q-10` · **Date:** 2026-11-04

**The spec, the code, the README, the docs and the Help Center of OpenPEDD are in English.** The
Spanish working drafts were translated on migration.

**Why:** it is open source, and a spec readable only in Spanish shuts out anyone who wants to
contribute. The largest market reads it without translation.

This governs OpenPEDD as a project. **The framework stays language-agnostic**: each project that uses
it writes its prose in its team's language, and only names are in English
([`RULE-05`](../foundations/rules/writing.md#rule-05)).
