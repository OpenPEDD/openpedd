# DEC-01 · The name: OpenPEDD

**Closes:** `Q-01` · **Date:** 2026-11-04

| What | Name |
|---|---|
| The methodology | **Product Engineering Driven Development** (PEDD) |
| The open framework | **OpenPEDD** |
| The CLI and short form | **`pedd`** |
| The paid plan | **OpenPEDD Cloud** |

Checked on 2026-11-04: free on npm (`openpedd`, `open-pedd`, `pedd`), on GitHub (`openpedd`) and as
`openpedd.com`, `.dev`, `.ai` and `.org`. This is not a trademark search.

**Why:** one name for the methodology and the tool; "Open" says it is an open standard; it is
product-oriented; every domain is free.

| Risk | How it is handled |
|---|---|
| It sounds like OpenSpec and OpenSDD | A visual identity and a message of its own: product, not code spec |
| "Open" is not distinctive as a trademark | PEDD is. PEDD™ exists in medicine (other industry, other classes): confirmed in the INPI and USPTO search |
| "Open" with a paid plan | The paid plan is called OpenPEDD Cloud |
| Pronunciation | The short form is `pedd` |

**Discarded:** OpenSDD (`opensdd.ai`, `deepagents-ai/OpenSDD`, npm `opensdd`); Product-Driven
Development (`pdd-kit`, and PDD is also *Prompt-Driven*); some 40 more candidates taken on npm,
GitHub or `.dev`.
